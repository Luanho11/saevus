# SAEVUS

Prototipo personal de un juego de acción en tercera persona de fantasía oscura, desarrollado con Unreal Engine 5.8 y C++. El proyecto combina movilidad rápida, combate cuerpo a cuerpo y exploración en escenarios de mazmorra.

## Sistemas principales

- Movimiento en tercera persona con dash direccional, carrera y desplazamiento por paredes.
- Combate con ataques normales y cargados, combos aéreos, guardia y contraataque.
- Tutorial jugable y mapa de práctica con goblins y un jefe.
- Interfaz y datos de juego implementados con C++, componentes de Unreal y Data Assets.
- Personajes y piezas de escenario creados con herramientas procedurales y Blender.

## Tecnologías

- Unreal Engine 5.8.
- C++ y herramientas integradas de Unreal Engine.
- Blender para modelado y generación de recursos.

## Abrir el proyecto

Abre [`SAEVUS.uproject`](SAEVUS.uproject) con Unreal Engine 5.8. Los scripts de verificación, recorrido y empaquetado están en `Herramientas/`.

El repositorio usa Git LFS para los recursos binarios de Unreal y arte. No se incluyen las carpetas generadas de compilación, caché y guardado.
